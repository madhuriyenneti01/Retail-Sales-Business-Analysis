
# Retail Sales & Business Performance Analysis

## Project Overview
This project analyzes retail sales data from 2014 to 2017 to understand sales performance, profitability, discount impact, and regional business performance.

An interactive Excel dashboard was developed to present key business insights and support data-driven decision-making.

## Dataset
- Source: Kaggle – Sample Superstore Dataset
- Records: 9,994
- Period: 2014–2017

## Tools Used
- Microsoft Excel
- PivotTables
- PivotCharts
- Power Query
- Conditional Formatting
- Slicers
- Excel Formulas

## Analysis Performed
1. Sales and profit analysis by category and sub-category.
2. Discount impact on profitability.
3. Regional sales and profit comparison.
4. Monthly sales trend analysis.
5. Yearly sales performance.
6. Interactive dashboard development.

## Key Business Insights
- Technology generated the highest category profit.
- Furniture generated the lowest category profit.
- Tables recorded an overall loss.
- Higher discount bands (above 20%) were associated with negative profitability.
- The West region recorded the highest sales and profit.
- The Central region had the lowest profit margin.
- 2017 recorded the highest annual sales.

## Dashboard KPIs
- Total Sales: $2,297,200.86
- Total Profit: $286,397.02
- Profit Margin: 12.47%
- Total Orders: 5,009

## Project Files
- Excel workbook containing the analysis, PivotTables, charts, and interactive dashboard.

## Conclusion
This project demonstrates how Excel can be used to clean, analyze, visualize, and interpret retail business data to identify trends and profitability challenges.
